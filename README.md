# Cloud-Based Online Examination System

## Project Overview

The Cloud-Based Online Examination System is a web-based application developed to make the examination process easier, faster and more efficient. The main objective of this project is to provide a digital platform where students can participate in online examinations and administrators can manage exams and monitor student performance.

This project is developed using HTML, CSS and JavaScript for the frontend, while Node.js and Express.js are used for backend development. The application provides a simple and responsive interface that can be accessed through a web browser.

## Key Features

1. **Student Registration and Login:** Students can create their accounts and securely log in to access available examinations.
2. **Admin Login:** Administrators have a separate login facility to manage examination-related activities.
3. **Exam Management:** Admins can create MCQ-based examinations by adding questions, four options and correct answers.
4. **Timed Examination:** Each examination has a fixed duration. A countdown timer helps students complete their exams within the given time.
5. **Automatic Evaluation:** The system automatically checks submitted answers and calculates the student's score.
6. **Result History:** Students can view their examination results, while administrators can monitor submitted results.
7. **Role-Based Access:** Separate permissions are provided for students and administrators.

## Technologies Used

- Frontend: HTML, CSS and JavaScript
- Backend: Node.js and Express.js
- Authentication: Express Session and bcryptjs
- Security: Password hashing and role-based authorization
- Data Storage: JSON-based file storage
- Deployment: Render Cloud Hosting
- Version Control: Git and GitHub

## Working of the Project

Students register or log in to the system and access the available examinations. After starting an examination, they answer multiple-choice questions within the given time. Once submitted, the backend evaluates their answers and generates the result automatically.

The administrator can log in separately, create examinations, manage questions and view examination results.

## Conclusion

This project demonstrates how web technologies and cloud hosting can be used to develop an online examination platform. It provides practical learning experience in frontend development, backend programming, authentication, API handling, version control and cloud deployment. Future improvements may include PostgreSQL database integration, persistent session management, examination scheduling and detailed performance analytics.
